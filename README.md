# interactive-portfolio-room

A single-page interactive developer portfolio experience built as a stylized room scene.

## Features
- Animated room entrance with glowing environment
- Clickable room objects reveal profile, skills, education, experience, projects, and contact
- Clean, modern portfolio layout with layered UI panels
- Responsive design for desktop and mobile

## Run locally
Open `index.html` in a browser, or serve the folder with any static file server.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customize content
Edit the `portfolioData` object inside `script.js` to replace the sample developer details with your own name, skills, projects, and education.

## Files
- `index.html` — page structure and room elements
- `styles.css` — design, animation, and responsive layout
- `script.js` — content and interactivity
